# Database Schema

Managed by Prisma v5 (`prisma/schema.prisma`). Hosted on Neon (PostgreSQL).

## Models

### User
Created automatically by NextAuth (`@auth/prisma-adapter`). One user per Google account.

| Field | Type | Notes |
|---|---|---|
| id | String (cuid) | PK |
| email | String | unique |
| emailVerified | DateTime? | required by NextAuth adapter |
| name | String? | from Google profile |
| image | String? | from Google profile |
| claimedPlayer | Player? | one-to-one; null until user claims a player |
| loggedGames | Game[] | games this user has logged |

### Player
Represents a Root player identity. **Global** — shared across groups, not per-group.

| Field | Type | Notes |
|---|---|---|
| id | String (cuid) | PK |
| name | String | globally unique, case-insensitive — enforced by `CREATE UNIQUE INDEX "Player_name_key" ON "Player" (lower(name))` (NOT a Prisma `@unique`) |
| globalElo | Float | default 1000; recalculated from all games across all groups whenever any game is created or deleted anywhere |
| claimedById | String? | unique FK → User; enforces one-to-one claim at DB level |
| groups | GroupPlayer[] | memberships |
| gamePlayers | GamePlayer[] | game participations |

### Group
A leaderboard group with a shareable join code.

| Field | Type | Notes |
|---|---|---|
| id | String (cuid) | PK |
| name | String | display name |
| joinCode | String | unique, 8-char alphanumeric (generated by `src/lib/nanoid.ts`) |
| players | GroupPlayer[] | roster |
| games | Game[] | game history |

### GroupPlayer
Join table: Player ↔ Group. Composite PK `(groupId, playerId)`.

| Field | Type | Notes |
|---|---|---|
| role | Role enum | ADMIN \| MEMBER |
| groupElo | Float | default 1000; recalculated from that group's games whenever any game in the group is created or deleted |
| joinedAt | DateTime | |

### Game

| Field | Type | Notes |
|---|---|---|
| id | String (cuid) | PK |
| groupId | String | FK → Group |
| date | DateTime (Date only) | |
| victoryType | VictoryType enum | SCORE \| DOMINATION \| COALITION |
| isVirtual | Boolean | default true |
| hasHirelings | Boolean | default false |
| loggedByUserId | String? | FK → User (SetNull on delete) |
| players | GamePlayer[] | |

### GamePlayer
One row per player per game. `isWinner` replaces a separate winner table.

| Field | Type | Notes |
|---|---|---|
| id | String (cuid) | PK |
| gameId | String | FK → Game (Cascade) |
| playerId | String | FK → Player |
| faction | String | free-text faction name (see valid factions in games API) |
| isWinner | Boolean | default false |

## Enums
- `Role`: `ADMIN`, `MEMBER`
- `VictoryType`: `SCORE`, `DOMINATION`, `COALITION`

## Key constraints
- Case-insensitive unique player names: custom SQL index in migration `20260610000008_case_insensitive_player_names`
- One claimed player per user: `Player.claimedById @unique`
- One user per player: enforced by the above unique constraint
